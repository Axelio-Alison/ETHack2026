# Data

The structured ESG notebook uses these two inputs:

- `ESGData.xlsx` — Bloomberg-derived company ESG, emissions, workforce, policy, and governance fields.
- `sp500_esg_annual_features_2012_2024.csv` — 500-company annual panel used for company identity and the TRI, CFPB, CPSC, and openFDA regulatory adjustment.

`ESGData_Practical_Data_Dictionary.pdf` documents the workbook fields. Raw regulatory downloads and generated score outputs are kept out of this folder so the repository stays compact.
